Proposta da solução

Uma API acompanha o veículo da abertura da Ordem de Serviço até a entrega

Ordem de Serviço

  • Cliente por CPF ou CNPJ e dados do veículo
  • Serviços, peças e insumos
  • Orçamento e aprovação

Acompanhamento

  • Seis status controlados pelo sistema
  • Transições automáticas
  • Consulta do cliente pela API

Gestão administrativa

  • Clientes, veículos, serviços e peças
  • Controle de estoque
  • Tempo médio de execução

Banco de dados

PostgreSQL: o fluxo da OS exige transações e integridade fortes

ACID

Reserva, baixa e mudança de status alteram várias tabelas como uma só operação.

Integridade

CPF/CNPJ e placa únicos, chaves estrangeiras e CHECK de saldo.

Concorrência

Lock de linha no estoque: a última peça não vai para duas ordens.

Isolamento

Um schema por módulo, versionado com Flyway.
